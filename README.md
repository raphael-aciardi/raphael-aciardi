## 📌 Sobre Mim

Sou desenvolvedor de software com experiência em **aplicações web e mobile, APIs, bancos de dados, integrações e sustentação de sistemas em produção**.

Atualmente atuo na **Biolecce**, onde sou responsável pela sustentação e evolução das aplicações, participando desde o levantamento de necessidades com os usuários até o desenvolvimento, testes, versionamento e deploy.

Trabalho principalmente com **React, TypeScript, NestJS, Node.js, Supabase e PostgreSQL**, além de atuar com **RLS, arquitetura orientada a features, GitHub Actions e CI/CD**.

Na Biolecce, desenvolvi soluções como **CRM para o setor comercial, módulo de PCP e um sistema de atendimento integrado ao WhatsApp e IA**, além de participar do desenvolvimento de uma nova versão da plataforma utilizando **React, Vite, NestJS e PostgreSQL**.

Meu objetivo é continuar evoluindo como **Full Stack Developer**, aprofundando meus conhecimentos em **backend, arquitetura e engenharia de software**.
